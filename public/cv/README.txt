CV (LaTeX source + compiled PDF)
==================================

This folder holds the Academic CV used by the "Download CV" button on the
About page. Files here are copied verbatim by Vite into dist/cv/.

Files:
- cv.tex     LaTeX source for the CV (compiles to cv.pdf)
- latexmkrc  latexmk build configuration
- cv.pdf     compiled output (generated by GitHub Actions, NOT committed)

Build pipeline:
  GitHub Actions (.github/workflows/deploy.yml) uses xu-cheng/latex-action
  to compile cv.tex -> cv.pdf on every push to main, before vite build.
  The resulting PDF is included in the deployed dist/ automatically.

To compile locally (requires a LaTeX distribution, e.g. TeX Live / MiKTeX):
    cd public/cv
    latexmk -pdf cv.tex
